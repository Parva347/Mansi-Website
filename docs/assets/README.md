# Assets

This directory contains all visual assets for the Plaately website.

## Structure

logo/
- Primary logo
- White logo
- Black logo
- SVG files
- Transparent PNG

catalogue/
- Product catalogue PDF

products/
- Individual product photographs
- Grouped by collection if possible

factory/
- Manufacturing facility
- Machines
- Packaging
- Warehouse
- Office

lifestyle/
- Hospitality
- Restaurants
- Hotels
- Buffet setups
- Product lifestyle photography

Only authentic Plaately assets should be stored here.
Do not use stock images unless explicitly approved.
