# Design Principles

## Purpose

This document defines the visual language, user experience principles, and interface standards for the Mansi Industries website.

Every page, component and interaction should follow these guidelines.

If there is ever a conflict between convenience and design quality, choose the option that results in a more premium and timeless experience.

---

# Overall Design Philosophy

The website should feel like the digital flagship of an established premium manufacturer.

It should never resemble:

- Shopify templates
- Bootstrap themes
- Startup landing pages
- SaaS dashboards
- Consumer ecommerce websites

Instead it should resemble:

- Luxury furniture catalogues
- Hospitality manufacturers
- Premium industrial brands
- Architectural publications
- Editorial magazines

The experience should feel calm, elegant and deliberate.

---

# First Impression

Within five seconds the visitor should understand:

- Mansi Industries manufactures premium melamine tableware.
- Products are available only for wholesale.
- The company is established and trustworthy.
- Products are designed for hospitality businesses.
- The website is premium.

---

# Visual Hierarchy

The hierarchy should always be:

Photography

↓

Headline

↓

Supporting copy

↓

Primary action

↓

Secondary information

Never allow buttons, icons or decorative elements to compete with the products.

---

# Layout Principles

Every section should have generous whitespace.

Avoid cramped layouts.

Avoid equal-sized repetitive blocks.

Prefer asymmetrical editorial compositions.

Allow breathing room between sections.

Content should feel curated rather than densely packed.

---

# Grid System

Use a modern responsive grid.

Desktop

12-column layout.

Tablet

8-column layout.

Mobile

4-column layout.

Spacing should remain consistent across breakpoints.

---

# Spacing

Whitespace is a design element.

Never reduce spacing simply to fit more content.

Prefer fewer elements with more breathing room.

Every section should feel intentional.

---

# Typography

Typography should communicate quality.

Use:

Elegant serif for headlines.

Modern sans-serif for interface and body text.

Monospace only for:

SKU

Product Codes

Dimensions

Specifications

Avoid decorative fonts.

Avoid overly condensed fonts.

Avoid generic combinations that resemble templates.

---

# Headlines

Headlines should be:

Short

Confident

Professional

Examples:

Premium Melamine Tableware

Manufactured for Hospitality

Built for Commercial Dining

Avoid:

Welcome

Discover

Experience Excellence

Elevate Dining

---

# Body Copy

Body copy should be:

Simple

Professional

Honest

Readable

Do not exaggerate.

Never use unnecessary marketing language.

---

# Buttons

Buttons should feel premium.

Primary button

Solid

Strong contrast

Minimal radius

Secondary button

Outlined

Minimal

Ghost button

Text only

Avoid:

Oversized rounded pills

Heavy shadows

Bright gradients

Animated borders

---

# Product Cards

Product cards should prioritise photography.

Visible:

Image

Product Name

SKU

Collection

Hover:

MRP

Add to Quote

Cards should not resemble ecommerce shopping cards.

---

# Product Photography

Photography is the hero.

Images should be:

Large

High quality

Consistent

Professionally cropped

Maintain equal visual quality across the catalogue.

Never stretch images.

Never distort aspect ratios.

---

# Colours

Use a restrained palette.

Backgrounds should remain neutral.

Accent colours should support the products rather than dominate them.

Avoid bright saturated colours.

Avoid rainbow accents.

---

# Icons

Use icons sparingly.

Icons support information.

They do not become decoration.

Avoid large circular icon sections.

---

# Animation

Animations should feel expensive.

Slow.

Purposeful.

Natural.

Use:

Fade

Slide

Scale

Opacity

Avoid:

Bounce

Spin

Elastic motion

Flashing

Parallax overload

Animations should never distract from the products.

---

# Navigation

Navigation should remain simple.

Logo

Home

Products

About

Contact

Quote

Sticky navigation.

Smooth transitions.

No mega menus unless necessary.

---

# Catalogue

Catalogue browsing should feel effortless.

Instant search.

Category filters.

Fast loading.

Responsive layout.

Minimal distractions.

---

# Quote Drawer

The quote drawer replaces the shopping cart.

It should:

Slide from the right.

Remain persistent.

Allow quantity adjustments.

Generate a WhatsApp enquiry.

Never resemble a checkout flow.

---

# Contact Section

Contact information should be immediately accessible.

Address

Phone

WhatsApp

Email

Business Hours (if available)

Google Maps

---

# Footer

Footer should reinforce trust.

Business details.

Navigation.

Contact information.

Wholesale notice.

Copyright.

Avoid clutter.

---

# Mobile Experience

Mobile is equally important.

Large tap targets.

Comfortable spacing.

Fast loading.

No horizontal scrolling.

Catalogue must remain easy to browse.

---

# Accessibility

Every page must support:

Keyboard navigation.

Visible focus states.

Semantic HTML.

ARIA labels.

Alt text.

Colour contrast compliance.

---

Performance

95+

Accessibility

95+

SEO

95+

95+

Less than 2 seconds.

---

# SEO

Every page should include:

Meaningful titles.

Meta descriptions.

Structured headings.

Open Graph metadata.

Schema markup.

Optimised images.

---

# Things Never To Do

Never invent statistics.

Never invent awards.

Never invent certifications.

Never invent customers.

Never use placeholder text in production.

Never use lorem ipsum.

Never use stock business people.

Never create fake testimonials.

Never copy competitors.

Never create a consumer ecommerce experience.

---

# Definition of Premium

Before completing any feature ask:

Would this design look believable on the website of an internationally respected manufacturing company?

If the answer is no,

redesign it.

Every decision should increase trust, quality and timelessness.

The website should feel custom-designed rather than AI-generated.
